# Small Python Projects

This folder contains small Python projects created while learning and practising Python.

## Projects

### 1. Stone, Paper, Scissors Game
A game where the player competes against the computer using random choices.

### 2. High Score Game
Generates a random score and saves the highest score in a text file.

### 3. Multiplication Tables Generator
Generates multiplication tables from 2 to 20 and saves them in separate text files.

### 4. Word Replacer
Replaces specified words in a text file with hash symbols (`#`).

### 5. Find a Word in a File
Searches a text file for a specific word.

### 6. Find Word's Line Number
Finds the line number where a specific word first appears in a text file.

### 7. Inches to Centimeters Converter
Converts inches into centimeters using a Python function.

### 8. Employee Class
Demonstrates Python classes, objects, and constructors.

### 9. Calculator Using a Class
Calculates the square, cube, and square root of a number.

## Concepts Practised

- Variables and data types
- Conditional statements
- Loops
- Functions and recursion
- Object-Oriented Programming (OOP)
- File handling
- Lists and dictionaries
- Random numbers

## How to Run

Make sure Python is installed on your computer. Open a terminal in the project folder and run a Python file:

```bash
python filename.py
```
