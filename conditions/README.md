# Python Conditional Statements

This folder contains Python programs created to practise conditional statements.

## Topics Covered

- `if`, `elif`, and `else` statements
- Comparison operators (`<`, `>`, `==`, `!=`)
- Logical operators (`and`, `or`, `not`)
- Even and odd numbers
- Grade calculator
- Pass or fail checker
- Prime number checker
- FizzBuzz program

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in this folder.
4. Run a Python file using:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python file you want to run.

These programs are part of my Python learning journey and help me practise decision-making in Python.
