# Stone, Paper, Scissors Game

## Description
A simple Python game where the player competes against the computer. The computer randomly chooses Stone, Paper, or Scissors, and the program determines the winner.

## Features
- Random computer choices
- User input for selecting a move
- Automatic winner determination
- Invalid input handling

## Rules
- Stone beats Scissors.
- Scissors beats Paper.
- Paper beats Stone.
- Matching choices result in a draw.

## Concepts Learned
- Python `random` module
- Dictionaries
- User input and output
- Conditional statements (`if`, `elif`, `else`)
- Logical operators
- String methods (`lower()` and `strip()`)

## How to Run
Make sure Python is installed, open a terminal in this folder, and run:

```bash
python stone_paper_scissors.py
```
